# 워크래프트 3 유즈맵 개발 프로젝트

## 1. 프로젝트 개요

워크래프트 3 월드 에디터(World Editor)를 사용하여
**「데이아 빌리언즈(The Day Before 같은 느낌)의 기지 방어 + 좀비 생존형 협동 유즈맵」**을 제작한다.

게임의 핵심은 다음과 같다.

> 플레이어들이 하나의 기지를 건설하고 방어하면서 끊임없이 몰려오는 좀비를 처치한다.
> 게임 시작 후 약 20분 동안 기지를 지키면 생존 성공으로 게임을 클리어한다.
> 게임이 끝난 후 클리어 횟수와 경험치를 획득하며, 경험치에 따라 이병 → 일병 → 상병 → 병장 등의 계급이 상승한다.

게임은 1~6인 협동 플레이를 기본으로 설계한다.

---

# 2. 가장 중요한 개발 원칙

반드시 실제 워크래프트 3 월드 에디터에서 사용할 수 있는 구조로 작성한다.

가능하면 GUI 트리거보다 **JASS 중심**으로 시스템을 구현한다.

단순히 예제 코드만 작성하지 말고 실제 맵에 넣어서 사용할 수 있도록 작성한다.

모든 시스템은 서로 독립적인 모듈 형태로 구성한다.

예:

```text
InitSystem
WaveSystem
ZombieSystem
BaseSystem
BuildingSystem
ResourceSystem
TimerSystem
VictorySystem
DefeatSystem
ExpSystem
RankSystem
SaveLoadSystem
UISystem
EventSystem
```

각 시스템의 역할을 명확하게 분리한다.

---

# 3. 게임 기본 구조

게임은 다음과 같은 구조로 진행된다.

```text
게임 시작
    ↓
플레이어 배치
    ↓
기지 건설
    ↓
좀비 등장
    ↓
시간 경과
    ↓
좀비 웨이브 강화
    ↓
대규모 좀비 공격
    ↓
최종 웨이브
    ↓
20분 생존
    ↓
게임 클리어
    ↓
EXP 지급
    ↓
클리어 횟수 증가
    ↓
계급 상승 여부 확인
    ↓
Save Code 생성
```

반대로 핵심 기지가 파괴되면:

```text
기지 파괴
    ↓
GAME OVER
    ↓
생존 시간 기록
    ↓
보상 계산
    ↓
Save Code 생성
```

---

# 4. 게임 시간

게임의 기본 목표 시간은 **20분**이다.

게임 시작과 동시에 20분 카운트다운을 시작한다.

HUD에는 항상 다음 정보가 표시된다.

```text
SURVIVAL TIME

19:42
```

또는

```text
남은 시간 : 19:42
```

1초마다 갱신한다.

시간이 20:00에 도달하면 즉시 생존 성공 처리를 한다.

---

# 5. 기지 시스템

맵 중앙에 플레이어들의 공동 기지를 배치한다.

핵심 건물은 다음과 같다.

```text
사령부
```

사령부가 파괴되면 게임에서 패배한다.

기지 주변에는 플레이어가 방어 시설을 건설할 수 있다.

기본 건물:

```text
사령부
벽
문
감시탑
기관총 포탑
화염 포탑
병영
발전소
창고
수리 시설
탄약고
```

건물마다:

```text
가격
건설 시간
체력
방어력
공격력
공격 속도
사거리
전력 사용량
```

등의 데이터를 가진다.

---

# 6. 건설 시스템

플레이어는 게임 중 자원을 사용하여 건물을 건설할 수 있다.

예:

```text
기관총 포탑

Gold : 150
Iron : 50
Power : 10
Build Time : 5 sec
```

건설 완료 전에는 건설 중인 상태를 표시한다.

건물이 파괴되면 해당 건물의 기능도 제거한다.

건물은 업그레이드할 수 있도록 확장 가능한 구조로 만든다.

---

# 7. 자원 시스템

게임에는 최소한 다음 자원을 사용한다.

```text
Gold
Iron
Power
Research
```

HUD에 항상 현재 자원을 표시한다.

예:

```text
GOLD : 1250
IRON : 340
POWER : 85
RESEARCH : 12
```

자원은 다음과 같은 방법으로 획득할 수 있다.

```text
좀비 처치
자원 상자
맵의 자원 지점
특정 이벤트
시간 보상
```

# 8. 좀비 시스템

좀비는 맵 외곽 또는 지정된 스폰 지역에서 생성된다.

좀비는 기본적으로 기지를 향해 이동한다.

기지에 도착하면:

```text
벽
↓
문
↓
방어 건물
↓
사령부
```

등의 대상을 공격한다.

좀비가 방어 시설을 무시하고 지나가지 않도록 기본적인 공격 우선순위를 구현한다.

---

# 9. 좀비 종류

최소 다음 종류를 지원한다.

## 일반 좀비

```text
HP : 100
Damage : 10
Move Speed : 180
Attack Speed : 1.5
```

## 빠른 좀비

```text
HP : 70
Damage : 8
Move Speed : 300
Attack Speed : 1.2
```

## 탱커 좀비

```text
HP : 800
Damage : 40
Move Speed : 100
Attack Speed : 2.0
```

## 원거리 좀비

```text
HP : 300
Damage : 25
Range : 500
```

## 보스 좀비

```text
HP : 10000
Damage : 100
Move Speed : 120
```

수치는 실제 게임 밸런스에 맞게 쉽게 수정할 수 있도록 상수 또는 설정 테이블로 분리한다.

# 10. 웨이브 시스템

시간이 지나갈수록 좀비 웨이브가 강해진다.

기본적인 웨이브 구조:

```text
0~2분
정찰 / 소규모 좀비

2~5분
소규모 공격

5~8분
1차 대규모 공격

8~12분
강화 좀비 등장

12~15분
대규모 웨이브

15~18분
특수 좀비 등장

18~20분
최종 웨이브
```

웨이브가 진행될수록 다음 요소가 증가한다.

```text
좀비 수
좀비 HP
좀비 공격력
좀비 이동속도
특수 좀비 등장 확률
보스 등장 확률
```

단순히 숫자만 증가시키지 말고 웨이브마다 다른 구성을 사용할 수 있도록 설계한다.

예:

```text
Wave 1
Normal Zombie x 10

Wave 2
Normal Zombie x 20
Fast Zombie x 5

Wave 3
Normal Zombie x 30
Fast Zombie x 10
Tank Zombie x 2
```

---

# 11. 최종 웨이브

18분부터 20분까지는 최종 방어전으로 만든다.

HUD:

```text
================================
        FINAL HORDE
================================

남은 시간 : 01:32

WARNING!

대규모 좀비 무리가 접근하고 있습니다.
================================
```

20분까지 살아남으면:

```text
SURVIVAL SUCCESS
```

를 표시한다.

# 12. 승리 조건

기본 승리 조건:

```text
게임 시작 후 20분 생존
```

20분이 되는 순간 모든 좀비 스폰을 종료한다.

남아있는 좀비를 처리하고 게임 결과 화면을 표시한다.

예:

```text
================================
          SURVIVAL CLEAR
================================

생존 시간 : 20:00
좀비 처치 : 1,248
건물 생존 : 83%

CLEAR!

+1000 EXP
+1 CLEAR

================================
```

# 14. 플레이어 시스템

1~6명의 플레이어가 협동 플레이한다.

각 플레이어는 자신의 영웅 또는 생존자 유닛을 가진다.

예:

```text
Player 1
돌격병

Player 2
엔지니어

Player 3
저격수

Player 4
의무병

Player 5
중화기병

Player 6
정찰병
```

초기 버전에서는 직업 시스템을 단순하게 만들고 추후 확장할 수 있도록 한다.

---

# 15. 플레이어 역할

기본 직업:

### 돌격병

전투 능력 중심.

### 엔지니어

건설 및 수리 중심.

### 저격수

장거리 공격 중심.

### 의무병

아군 회복 중심.

### 중화기병

강력한 범위 공격.

### 정찰병

빠른 이동 및 시야 확보.

각 직업의 능력은 나중에 쉽게 추가할 수 있도록 데이터 중심으로 작성한다.

+1000 EXP

+100 EXP

# 20. Save / Load 시스템

워크래프트 3 환경에서 영구 저장이 가능한 구조를 고려한다.

가능하면 **Save Code / Load Code 방식**으로 구현한다.

게임 종료 시:

```text
SAVE CODE

A7K9-XP32-91FQ-K82M
```

같은 문자열을 생성한다.

코드 안에는 최소한 다음 정보를 저장한다.

```text
Rank
EXP
Clear Count
Total Kills
Best Survival Time
```

다음 게임 시작 시 플레이어가 채팅 명령어 등을 이용해 코드를 입력하면 데이터를 복구할 수 있도록 한다.

예:

```text
-load A7K9-XP32-91FQ-K82M
```

코드가 변조되지 않았는지 확인하기 위한 체크값 또는 간단한 검증 시스템도 고려한다.

단, 워크래프트 3 버전 및 실제 맵 환경에서 사용할 수 없는 API를 임의로 만들지 않는다.

# 25. 중요한 JASS 개발 규칙

다음 사항을 반드시 지킨다.

1. 실제 Warcraft 3 JASS 문법을 사용한다.
2. 존재하지 않는 native/function을 임의로 만들지 않는다.
3. 핸들 누수(leak)를 최대한 방지한다.
4. 타이머를 남발하지 않는다.
5. 그룹(group), 위치(location), 특수효과(effect) 등의 누수를 관리한다.
6. 플레이어별 데이터를 배열 또는 구조화된 방식으로 관리한다.
7. 맵의 최대 플레이어 수를 고려한다.
8. 모든 상수는 코드 상단에서 쉽게 수정할 수 있도록 한다.
9. 시스템 간 의존성을 최소화한다.
10. 실제 World Editor에서 컴파일 가능한 코드인지 확인한다.
11. GUI 트리거와 JASS를 혼합해야 하는 경우 어느 부분을 GUI에서 설정해야 하는지 명확하게 설명한다.
12. 사용할 Warcraft 3 버전에서 지원되지 않는 기능은 사용하지 않는다.

# 26. 개발 순서

처음부터 모든 기능을 한 번에 작성하지 않는다.

다음 순서로 개발한다.

## Phase 1

기본 게임 루프

```text
게임 시작
↓
20분 타이머
↓
좀비 스폰
↓
좀비 이동
↓
기지 공격
```

## Phase 2

웨이브 시스템

```text
Wave 1
Wave 2
Wave 3
...
Final Wave
```

## Phase 3

# 27. 내가 원하는 답변 방식

코드를 작성할 때 설명만 하지 말고 **실제로 복사해서 사용할 수 있는 전체 코드**를 제공한다.

각 단계마다:

```text
1. 필요한 World Editor 설정
2. 필요한 유닛
3. 필요한 건물
4. 필요한 지역(Rect)
5. 필요한 변수
6. JASS 코드
7. World Editor에 넣는 방법
8. 테스트 방법
9. 예상되는 결과
10. 발생 가능한 오류
```

순서로 설명한다.

코드가 길어지는 경우 여러 파일 또는 여러 코드 블록으로 분리한다.

# 28. 첫 번째 작업

우선 다른 기능을 구현하지 말고 **Phase 1 프로토타입**부터 만든다.

첫 번째 목표는 다음과 같다.

```text
게임 시작
    ↓
10초 준비시간
    ↓
좀비 스폰 시작
    ↓
좀비가 기지를 향해 이동
    ↓
좀비가 기지 건물을 공격
    ↓
20분 타이머 시작
    ↓
시간이 지나면 좀비 스폰 증가
    ↓
사령부 파괴
    → 패배

20분 생존
    → 승리
```

단, 개발 테스트를 쉽게 하기 위해

```text
DEBUG_MODE = true
```

를 제공한다.

DEBUG_MODE에서는 20분을 기다리지 않고 예를 들어 60초 또는 120초로 테스트할 수 있게 한다.

# 29. 최종적으로 목표하는 게임

최종 완성본은 다음과 같은 게임이 되어야 한다.

```text
                ZOMBIE HORDE
       🧟 🧟 🧟 🧟 🧟 🧟 🧟
             ↓↓↓↓↓↓↓

   🧱 🧱 🧱 🧱 🧱 🧱 🧱
   🧱   🗼       🗼    🧱
   🧱                 🧱
   🧱    🏠 사령부     🧱
   🧱                 🧱
   🧱   🗼       🗼    🧱
   🧱 🧱 🧱 🧱 🧱 🧱 🧱

             ↑
        PLAYER TEAM

================================

TIME        03:42 / 20:00
WAVE             7
BASE HP          82%

GOLD            1250
IRON             340
POWER             85

RANK             이병
EXP          2,430 / 5,000
CLEAR COUNT          7

================================
```

게임을 반복해서 플레이하면서

```text
생존
↓
클리어
↓
EXP
↓
계급 상승
↓
새로운 능력 / 건설물 / 장비 해금
↓
더 높은 난이도 도전
↓
다시 생존
```

이라는 성장 구조를 만드는 것이 최종 목표다.
